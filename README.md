# Bingus Vibe (aka Cutesy Cat of the Day)

![Cutesy Cat of the Day app](docs/ccotd.png)

Cutesy Cat of the Day is an experiment of morbid curiosity, in which the [MS Bingus Chatbot](https://msbingus.dansakamoto.com) was asked to suggest an app that it "wanted" to build, and then that idea was subsequently "vibe coded" by it.

## Requirements

Node.js

## Quickstart

```
npm i
npm start
```

Visit localhost:3000 in your browser.
